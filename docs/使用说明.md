## 2 安装与启动

### 2.1 从源码运行

```bash
# 克隆仓库
git clone http://hh.yuxtk.com:3030/sheldon/Q-caliper.git
cd Q-Caliper

# 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动应用
python main.py
```

### 2.2 开发环境

```bash
pip install -r requirements-dev.txt

# 代码检查
ruff check .

# 类型检查
mypy q_caliper/

# 运行测试
pytest
```

## 3 界面总览

应用启动后为 Fluent Design 风格窗口 (960x680), 左侧为导航栏:

| 导航项 | 图标 | 功能 |
|--------|------|------|
| **数据中心** | Home | 加载和预览数据文件 |
| **Cpk 分析** | Pie | 过程能力分析 |
| **GRR 分析** | People | 量具重复性与再现性 |
| **MSA 分析** | Speed | 偏差分析与线性分析 |

所有分析模块共享同一份加载数据, 在数据中心加载一次即可在各模块中使用。

## 4 数据中心

### 4.1 加载数据

支持两种加载方式:

- **拖拽加载**: 将 `.xlsx` / `.xlsm` / `.csv` 文件直接拖入虚线区域
- **浏览加载**: 点击「浏览文件」按钮, 在文件对话框中选择

### 4.2 数据预览

加载成功后, 表格区域自动显示前 100 行数据, 包含:

- 文件名和行列数信息
- 完整的表头 (列名)
- 自动识别数值列和文本列

### 4.3 数据传递

加载的数据会自动同步到所有分析模块:

- Cpk 分析: 自动填充数值列下拉框
- GRR 分析: 自动填充测量列 / 操作者列 / 零件列
- MSA 分析: 自动填充测量列和参考值列

## 5 Cpk 过程能力分析

### 5.1 操作流程

1. 在数据中心加载 Excel/CSV 文件
2. 切换到「Cpk 分析」页面
3. 在左侧「列映射」卡片中:
   - **测量列**: 从下拉框选择包含测量数据的数值列
   - **USL**: 设置规格上限 (上规格限)
   - **LSL**: 设置规格下限 (下规格限)
   - **子组大小**: 设置子组大小 (默认 1, 即个体值)
4. 点击「计算 Cpk」按钮
5. 右侧直方图和下方结果表自动更新

### 5.2 结果说明

#### 分析结果表

| 指标 | 说明 |
|------|------|
| 均值 (Mean) | 数据的算术平均值 |
| 组内标准差 (sigma_within) | 基于子组极差估计的组内变异 |
| 总体标准差 (sigma_overall) | 数据的总体标准差 |
| Cp | 潜在过程能力指数 (仅考虑规格宽度) |
| Cpk | 实际过程能力指数 (考虑均值偏移) |
| Pp | 潜在过程性能指数 (使用总体标准差) |
| Ppk | 实际过程性能指数 (使用总体标准差) |
| USL / LSL | 规格上下限 |
| 超 USL 比例 | 超出规格上限的概率 |
| 低于 LSL 比例 | 低于规格下限的概率 |
| 总超规格比例 | 超出规格限的总概率 |

#### 正态性检验

| 指标 | 说明 |
|------|------|
| 检验方法 | n < 5000 使用 Shapiro-Wilk, 否则使用 Anderson-Darling |
| p 值 | p > 0.05 判定为正态分布 |

#### 直方图

- 蓝色柱状: 数据分布密度
- 红色曲线: 正态拟合曲线
- 红色虚线: USL / LSL 规格限
- 绿色实线: 数据均值
- 右上角标签: Cpk 值 (绿色 >= 1.33, 橙色 >= 1.0, 红色 < 1.0)

### 5.3 Cpk 判定标准

| Cpk 值 | 等级 | 说明 |
|---------|------|------|
| >= 1.67 | 优秀 | 过程能力充足 |
| >= 1.33 | 良好 | 过程能力满足要求 |
| >= 1.00 | 可接受 | 过程能力勉强满足 |
| < 1.00 | 不可接受 | 需要改进过程 |

## 6 GRR 量具重复性与再现性分析

### 6.1 数据格式要求

GRR 分析要求数据按以下结构排列:

| 零件 | 操作者 | 测量值 |
|------|--------|--------|
| P01 | Operator_1 | 50.12 |
| P01 | Operator_1 | 50.15 |
| P01 | Operator_1 | 50.10 |
| P01 | Operator_2 | 50.20 |
| ... | ... | ... |

- **零件数**: 建议 >= 10 个
- **操作者数**: 建议 >= 3 人
- **重复次数**: 每人每件至少 2 次, 建议 3 次

### 6.2 操作流程

1. 在数据中心加载 GRR 格式的 Excel 文件
2. 切换到「GRR 分析」页面
3. 在左侧参数设置中:
   - **测量列**: 选择包含测量值的数值列
   - **操作者列**: 选择标识操作者的列
   - **零件列**: 选择标识零件的列
   - **零件数 / 操作者数 / 重复次数**: 自动检测, 也可手动调整
4. 点击「计算 GRR」按钮
5. ANOVA 结果表和六图仪表板自动更新

### 6.3 数据验证

系统会自动校验:

- 零件数 >= 2, 操作者数 >= 2, 重复次数 >= 2
- 数据量 = 零件数 x 操作者数 x 重复次数
- 每个零件-操作者组合的数据量满足要求
- 零件数偏少 (< 10) 或操作者偏少 (< 3) 时给出建议

### 6.4 结果说明

#### ANOVA 方差分析表

| 来源 | 说明 |
|------|------|
| 零件 (Parts) | 零件间变异 |
| 操作者 (Operators) | 操作者间变异 |
| 交互 (Interaction) | 零件与操作者的交互效应 |
| 重复性 (Error) | 测量误差 (重复性) |
| 合计 (Total) | 总变异 |

#### GRR 指标

| 指标 | 说明 |
|------|------|
| 重复性 (EV) | 设备变异 (Equipment Variation) |
| 再现性 (AV) | 评价人变异 (Appraiser Variation) |
| 交互 (INT) | 评价人与零件的交互变异 |
| 零件 (PV) | 零件间变异 (Part Variation) |
| %GRR | GRR 占总变异的百分比 |
| ndc | 可区分的分级数 (Number of Distinct Categories) |

#### 判定标准

| 指标 | 可接受 | 可接受 | 不可接受 |
|------|--------|--------|----------|
| %GRR | < 10% | 10% - 30% | > 30% |
| ndc | >= 5 | - | < 5 |

### 6.5 六图仪表板

1. **按零件分组**: 展示每个零件的测量值分布 (箱线图)
2. **按操作者分组**: 展示每个操作者的测量值分布 (箱线图)
3. **操作者均值图**: 各操作者均值对比, 红线为总均值
4. **零件均值图**: 各零件均值对比, 红线为总均值
5. **零件x操作者交互图**: 不同操作者在各零件上的均值趋势
6. **变异分量占比**: 各变异分量占总变异的百分比 (饼图)

## 7 MSA 测量系统分析

### 7.1 偏差分析

#### 操作流程

1. 在数据中心加载数据文件
2. 切换到「MSA 分析」页面
3. 在「偏差分析设置」卡片中:
   - **测量列**: 选择包含测量值的数值列
   - **参考值**: 输入已知的参考值 (真值)
4. 点击「分析偏差」按钮

#### 结果说明

| 指标 | 说明 |
|------|------|
| 观测均值 | 测量数据的平均值 |
| 参考值 | 已知的参考/真值 |
| 偏差 (Bias) | 观测均值 - 参考值 |
| 偏差百分比 | 偏差占参考值的百分比 |
| t 统计量 | 单样本 t 检验统计量 |
| p 值 | p < 0.05 表示偏差显著 |
| 95% CI | 偏差的 95% 置信区间 |
| 显著性 | 显著 / 不显著 |

#### 偏差图

- 蓝色柱状: 测量值分布
- 绿色虚线: 参考值位置
- 红色实线: 观测均值位置

### 7.2 线性分析

#### 操作流程

1. 在数据中心加载数据文件
2. 切换到「MSA 分析」页面
3. 在「线性分析设置」卡片中:
   - **参考值列**: 选择包含不同参考值的列
   - **测量均值列**: 选择对应各参考值的测量均值列
   - **过程变异**: 输入过程变异值 (6 倍标准差)
4. 点击「分析线性」按钮

#### 数据格式要求

每个参考值对应一个测量均值 (多个参考值点):

| 参考值 | 测量均值 |
|--------|----------|
| 10 | 10.2 |
| 20 | 20.5 |
| 30 | 30.8 |
| 40 | 41.2 |
| 50 | 51.5 |

至少需要 3 个不同的参考值点。

#### 结果说明

| 指标 | 说明 |
|------|------|
| 斜率 (Slope) | 回归线斜率, 理想值为 0 |
| 截距 (Intercept) | 回归线截距, 理想值为 0 |
| R-squared | 决定系数, 越接近 1 线性关系越强 |
| 斜率 p 值 | p < 0.05 表示斜率显著不为 0 |
| P/T 比 | 精度与公差比 |
| 线性度 | 平均绝对偏差 |

#### 线性图

- 蓝色散点: 各参考值处的观测偏差
- 红色回归线: 偏差 vs 参考值的线性回归
- 绿色虚线: 零偏差线 (理想情况)

## 9 常见问题

### Q: 启动后界面文字显示为方框?

A: 系统缺少中文字体。请安装 Microsoft YaHei 或 SimHei 字体。

### Q: 加载 Excel 文件报错?

A: 确认文件格式为 `.xlsx` 或 `.xlsm`, 且未被其他程序锁定。CSV 文件请使用 UTF-8 编码。

### Q: GRR 计算提示「数据量不匹配」?

A: GRR 要求数据量 = 零件数 x 操作者数 x 重复次数。请确认每个零件-操作者组合都有相同数量的测量值。

### Q: Cpk 直方图中文标签显示为方框?

A: matplotlib 需要 CJK 字体支持。应用会自动检测系统字体, 如仍有问题请安装 Microsoft YaHei。

### Q: 如何导出分析报告?

A: PDF 报告导出功能将在第四阶段 (Typst 引擎) 实现。当前版本可截图保存结果。
