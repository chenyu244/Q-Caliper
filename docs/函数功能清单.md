### 1.1 cpk.py — Cpk/Ppk 过程能力分析

**路径**: `q_caliper/core/cpk.py`

#### 数据类

| 类名 | 字段 | 说明 |
|------|------|------|
| `NormalityResult` | `test_name: str` | 检验方法名称 (Shapiro-Wilk / Anderson-Darling) |
| | `statistic: float` | 检验统计量 |
| | `p_value: float` | p 值 |
| | `is_normal: bool` | 是否为正态分布 (p > alpha) |
| `CpkResult` | `mean: float` | 数据均值 |
| | `std_within: float` | 组内标准差 |
| | `std_overall: float` | 总体标准差 |
| | `cp: float` | Cp 指数 |
| | `cpk: float` | Cpk 指数 |
| | `pp: float` | Pp 指数 |
| | `ppk: float` | Ppk 指数 |
| | `usl: float \| None` | 规格上限 |
| | `lsl: float \| None` | 规格下限 |
| | `pct_above_usl: float` | 超出 USL 的比例 |
| | `pct_below_lsl: float` | 低于 LSL 的比例 |
| | `pct_total_out: float` | 总超规格比例 |

#### 公开函数

##### `normality_test(data, alpha=0.05) -> NormalityResult`

对数据进行正态性检验。

- **n < 5000**: 使用 Shapiro-Wilk 检验
- **n >= 5000**: 使用 Anderson-Darling 检验
- **最少数据量**: 8 个

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 输入数据 |
| `alpha` | `float` | 显著性水平, 默认 0.05 |

| 异常 | 条件 |
|------|------|
| `ValueError` | 数据点少于 8 个 |

##### `calculate_cpk(data, usl=None, lsl=None, subgroup_size=1) -> CpkResult`

计算 Cpk/Ppk 过程能力指数。

- 至少需要指定 USL 或 LSL 中的一个
- `subgroup_size > 1` 时使用子组极差法估计组内标准差 (d2 常数)
- `subgroup_size = 1` 时使用样本标准差

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 测量数据 |
| `usl` | `float \| None` | 规格上限 |
| `lsl` | `float \| None` | 规格下限 |
| `subgroup_size` | `int` | 子组大小, 默认 1 |

| 异常 | 条件 |
|------|------|
| `ValueError` | USL 和 LSL 均未指定 |

### 1.2 grr.py — GRR ANOVA 分析

**路径**: `q_caliper/core/grr.py`

#### 数据类

| 类名 | 字段 | 说明 |
|------|------|------|
| `AnovaRow` | `source: str` | 变异来源 |
| | `ss: float` | 平方和 (Sum of Squares) |
| | `df: int` | 自由度 |
| | `ms: float` | 均方 (Mean Square) |
| | `f_value: float` | F 统计量 |
| | `p_value: float` | p 值 |
| `GrrResult` | `var_repeatability: float` | 重复性方差 (EV) |
| | `var_reproducibility: float` | 再现性方差 (AV) |
| | `var_interaction: float` | 交互方差 (INT) |
| | `var_parts: float` | 零件方差 (PV) |
| | `var_total: float` | 总方差 |
| | `pct_grr: float` | GRR 百分比 |
| | `pct_part_variation: float` | 零件变异百分比 |
| | `ndc: int` | 可区分分级数 |
| | `f_statistic: float` | 零件 F 统计量 |
| | `p_value: float` | 零件 p 值 |
| | `anova_table: list[AnovaRow]` | 完整 ANOVA 表 |
| | `grand_mean: float` | 总均值 |
| | `part_means: list[float]` | 各零件均值 |
| | `operator_means: list[float]` | 各操作者均值 |
| | `cell_means: list[list[float]]` | 单元格均值 (零件 x 操作者) |
| | `raw_data: NDArray` | 原始数据三维数组 |
| | `n_parts: int` | 零件数 |
| | `n_operators: int` | 操作者数 |
| | `n_trials: int` | 重复次数 |

#### 公开函数

##### `validate_grr_data(n_parts, n_operators, n_trials, n_measurements) -> list[str]`

验证 GRR 研究参数, 返回警告/错误消息列表。空列表表示验证通过。

| 参数 | 类型 | 说明 |
|------|------|------|
| `n_parts` | `int` | 零件数 |
| `n_operators` | `int` | 操作者数 |
| `n_trials` | `int` | 重复次数 |
| `n_measurements` | `int` | 实际测量数据量 |

**检查规则**:
- 零件数 >= 2, 操作者数 >= 2, 重复次数 >= 2
- 数据量 = 零件数 x 操作者数 x 重复次数
- 建议零件数 >= 10, 操作者数 >= 3

##### `calculate_grr(data, n_parts, n_operators, n_trials) -> GrrResult`

使用 ANOVA 方法计算 GRR。

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 展平的测量数据 (零件 x 操作者 x 重复) |
| `n_parts` | `int` | 零件数 |
| `n_operators` | `int` | 操作者数 |
| `n_trials` | `int` | 每个组合的重复次数 |

**返回值**包含:
- 方差分量 (EV / AV / INT / PV)
- GRR 百分比和 ndc 分级数
- 完整 ANOVA 方差分析表
- 图表所需数据 (均值、单元格均值、原始数据)

### 1.3 msa.py — MSA 偏差与线性分析

**路径**: `q_caliper/core/msa.py`

#### 数据类

| 类名 | 字段 | 说明 |
|------|------|------|
| `BiasResult` | `mean_bias: float` | 平均偏差 |
| | `reference_value: float` | 参考值 |
| | `observed_mean: float` | 观测均值 |
| | `t_statistic: float` | t 检验统计量 |
| | `p_value: float` | p 值 |
| | `pct_bias: float` | 偏差百分比 |
| | `ci_lower: float` | 95% CI 下限 |
| | `ci_upper: float` | 95% CI 上限 |
| | `is_significant: bool` | 偏差是否显著 (p < alpha) |
| `LinearPoint` | `reference: float` | 参考值 |
| | `observed_mean: float` | 观测均值 |
| | `bias: float` | 该点偏差 |
| `LinearResult` | `slope: float` | 回归斜率 |
| | `intercept: float` | 回归截距 |
| | `r_squared: float` | 决定系数 R² |
| | `p_slope: float` | 斜率 p 值 |
| | `p_intercept: float` | 截距 p 值 |
| | `pct_linearity: float` | %Linearity (线性度百分比) |
| | `linearity: float` | 线性度 (平均绝对偏差) |
| | `points: list[LinearPoint]` | 各参考点数据 |
| | `regression_line_x: list[float]` | 回归线 X 坐标 |
| | `regression_line_y: list[float]` | 回归线 Y 坐标 |

#### 公开函数

##### `analyze_bias(data, reference_value, alpha=0.05) -> BiasResult`

偏差分析 (单样本 t 检验)。

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 测量数据 |
| `reference_value` | `float` | 已知参考值 |
| `alpha` | `float` | 显著性水平, 默认 0.05 |

**计算内容**:
- 偏差 = 观测均值 - 参考值
- 单样本 t 检验 (双侧)
- 偏差百分比 = 偏差 / 参考值 x 100%
- 95% 置信区间

##### `analyze_linearity(reference_values, observed_means, process_variation) -> LinearResult`

线性分析 (偏差 vs 参考值的线性回归)。

| 参数 | 类型 | 说明 |
|------|------|------|
| `reference_values` | `ArrayLike` | 参考值数组 |
| `observed_means` | `ArrayLike` | 各参考值对应的观测均值 |
| `process_variation` | `float` | 过程变异 (6 倍标准差) |

| 异常 | 条件 |
|------|------|
| `ValueError` | 参考值点少于 3 个 |

**计算内容**:
- 偏差 = 观测均值 - 参考值
- 线性回归 (斜率、截距、R²)
- P/T 比 = |斜率| x 过程变异
- 线性度 = 平均绝对偏差

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 测量数据 |
| `subgroup_size` | `int` | 子组大小 (2-10), 默认 5 |

**返回**: `(xbar_chart, r_chart)` 元组

生成 I-MR (个体值-移动极差) 控制图。

| 参数 | 类型 | 说明 |
|------|------|------|
| `data` | `ArrayLike` | 测量数据 |

**返回**: `(i_chart, mr_chart)` 元组

##### `detect_violations(values, limits, n_sigma=3.0) -> list[ViolationPoint]`

检测 Western Electric 八大判异准则违规。

| 参数 | 类型 | 说明 |
|------|------|------|
| `values` | `list[float]` | 数据值列表 |
| `limits` | `ControlLimits` | 控制限 |
| `n_sigma` | `float` | 控制限倍数, 默认 3.0 |

**八大判异准则**:

| 规则 | 描述 |
|------|------|
| Rule 1 | 点超出控制限 |
| Rule 2 | 连续 9 点在中心线同一侧 |
| Rule 3 | 连续 6 点递增或递降 |
| Rule 4 | 连续 14 点交替上下 |
| Rule 5 | 连续 3 点中 2 点在 A 区外 |
| Rule 6 | 连续 5 点中 4 点在 B 区外 |
| Rule 7 | 连续 15 点在 C 区内 |
| Rule 8 | 连续 8 点在 C 区外 (但均在控制限内) |

| 参数 | 类型 | 说明 |
|------|------|------|
| `n_factors` | `int` | 因子数 (>= 3) |
| `generator` | `str \| None` | 生成器字符串 (预留, 未实现) |
| `factor_names` | `list[str] \| None` | 因子名称 |
| `randomize` | `bool` | 是否随机化运行顺序 |

| 异常 | 条件 |
|------|------|
| `ValueError` | 因子数少于 3 |
